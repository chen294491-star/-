# 陈杰 · AI 视频与创意作品集

采用原生 HTML、CSS 和 JavaScript 的静态个人作品集，无需安装前端依赖或执行构建。

## 页面结构

1. **AI 视频作品**：动画类 AI、真人影视精品 AI 两类，各预留两个视频位；下方提供制作流程、制作规范、数据展示三个栏目。
2. **实习与项目成果**：三个项目展示位，包含项目背景、个人贡献、阶段成果与数据截图。
3. **游戏自媒体**：账号主页、内容定位、代表内容与运营数据，预留两个内容展示位。
4. **网媒与编导**：H5《生死72小时》的作品和获奖截图；一部微电影代表作，以及导演、镜头与剪辑思路。
5. **设计与写作**：UI 设计、推文作品两个补充板块。
6. **工具与工作流**：25 个工具按六个制作环节组织，支持选择工具、查看用途、播放与暂停流程演示。

《生死72小时》“2026 全国大学生新媒体创意大赛·全国二等奖”的信息由本人确认，截图待补。赛事方向参考[方正飞翔官方赛事说明](https://www.founderfx.cn/contest/index.jhtml)。

## 内容状态

当前是板块与交互骨架。成片、截图、账号、项目详情和数据均待重新补充，没有恢复已撤下的媒体或账号链接。数据用“—”显示，不填充示例成绩。

工具按流程用途展示，不设置熟练度评分或百分比。

## 本地查看

直接在浏览器中打开 `index.html`。也可以在本目录运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 六个主板块、展示位置与页面文字 |
| `portfolio.css` | 响应式布局、占位视觉与流程动画 |
| `portfolio.js` | 栏目切换、工具选择、流程演示、键盘与手机导航 |
| `content.js` | 简介、空作品列表、展示位数量、奖项、工具与流程数据 |
| `.nojekyll` | 静态托管标记 |

作品数组在 `works` 内，当前保持为空；预留位置数量在 `layout` 内。奖项与截图位置在 `award` 内，指标在 `metrics` 内，工具和流程分别在 `tools`、`workflow` 内。接入实际作品时，需要同步补上相应展示组件与媒体资源。

## 交互

- AI 视频分类和制作资料栏目均支持点击和键盘切换。
- 工具区点击节点选择环节，点击工具显示用途。
- “演示工作流”按顺序播放六个环节；可暂停，离开可见区域或页面后台时停止。
- 遵循系统的减少动态效果设置。
- 手机采用折叠菜单、自然滚动与单列内容布局。
- 页面可在本地文件模式运行。
